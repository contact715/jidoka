# Ресёрч не сдаётся без собственного аудита покрытия

Происхождение: Rejuvenation Nation, 2026-07-28. Владелец три раза подряд спросил
«ты точно всё проверил?», и каждый раз находились непокрытые источники. Его формулировка:
«ты должен сам себя всегда переспрашивать, чтобы этого больше не повторялось никогда».

## Правило

Перед сдачей любого ресёрча агент проводит ревизию покрытия сам и показывает её результат.

1. Выписать все релевантные источники.
2. Отметить: покрыт / не покрыт / непроверяем.
3. Закрыть все «не покрыт», до которых можно дотянуться.
4. В отчёте дать явный раздел «чего не проверил и почему».

## Типовые дыры, которые ловит это правило

| Дыра | Как выглядит | Как закрыть |
|---|---|---|
| Файл владельца прочитан по ссылке | Открыт один экран прототипа | Открыть файл целиком, пройти панель слоёв и все кластеры |
| Документация прочитана по первой странице | Прочитан обзор API | Пройти все разделы: авторизация, лимиты, webhooks, тарифы, комплаенс, отраслевые модули |
| Транскрипт разобран по верхам | Взяты явные решения | Перечитать на предмет нюансов модели бизнеса и оговорок |
| Публичные данные не сверены со словами клиента | Поверил на слово | Проверить профили, DNS, живые страницы |
| Конкурент назван, но не разобран | Упомянут в списке | Открыть, разобрать техстек и воронку |

## Композиция

Дополняет «No done without proof» (доказательство работы) и «A specific you inferred is not
a fact» (доказательство фактов). Здесь доказывается ПОЛНОТА охвата.
