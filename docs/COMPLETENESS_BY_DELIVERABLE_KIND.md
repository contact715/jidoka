# Полнота сдачи проверяется по ТИПУ РЕЗУЛЬТАТА, а не по расширению файла

Класс: `completeness-claimed-without-self-audit`.
Механизмы: `hooks/synthesis-coverage-gate.mjs`, `scripts/synthesis-coverage-audit.mjs`.
Введено 2026-08-17 (неделя W34).

## Замер, который это породил

Поиск по журналу сессий на строку «ты точно» дал **11 разных сессий за август**, в пяти
проектах. Каждый раз владелец спрашивал сам, и каждый раз что-то находилось.

Прежний гейт опознавал сдачу по расширению файла (`md|html|txt|doc|pdf`) плюс имя, похожее
на синтез. Под это определение попадает **один случай из одиннадцати**. Остальные десять
гейт не мог увидеть по построению, потому что сдача была не документом:

| Что спросил владелец | Тип сдачи | Видел ли прежний гейт |
|---|---|---|
| «так ты точно все применил в инбоксе с фигмы? все стили и spatial?» | перенос дизайна в код | нет |
| «Ты точно скачал весь бэк-энд на компьютер? Всё скачал?» | перенос чужого кода | нет |
| «Ты точно в этом плане всё покрыл? Все сценарии, исходы, кнопки» | план в переписке | нет |
| «ты точно все нашел, чтобы звук был неотличим» | ресёрч под качество | нет |
| «ты точно все проверил?» (ТЗ клиенту) | документ-синтез | да |

## Что взято и что осознанно НЕ взято

Взяты **два** типа, у которых источник истины сверяется машиной:

- **`design-port`** — перенос дизайна в код. Инвентарь макета (токены, названия стилей и
  слоёв) сверяется с текстом ИЗМЕНЁННОГО КОДА. «Применил ли ты все стили» это вопрос о
  коде, а не о документе.
- **`code-import`** — перенос чужого кода к себе. Полнота меряется РАЗНИЦЕЙ МНОЖЕСТВ
  ФАЙЛОВ, а не словами: у переноса дерева полнота это файлы.

**Не взяты** план в переписке и ресёрч под заданное качество. У них источник истины живёт в
переписке, машинной сверки нет. Это осознанный недобор, а не забывчивость.

Причина отказа важнее самого отказа: гейт, у которого нет исполнимого лечения, блокирует
работу и не даёт способа разблокироваться. Движок поймал ровно такой тупик на себе в этот
же день (класс `gate-remedy-cannot-satisfy-the-gate`: пре-пуш-гейт отказал, а его
предписанный `--sync` не мог абсорбировать ни одной строки). Повторять это здесь нельзя.

## Лечение, которым из блокировки выходят

```
# перенос чужого кода: какие файлы не доехали
node scripts/synthesis-coverage-audit.mjs --kind code-import \
  --source <папка-источник> --target <папка, куда переносили>

# перенос дизайна: какие токены и стили не доехали в код
node scripts/synthesis-coverage-audit.mjs --kind design-port \
  --source <файл с инвентарём макета> --target <папка с изменёнными компонентами>
```

Смысловая сверка субагентом засчитывается наравне с машинной: на переносе дизайна субагент,
сравнивший макет с кодом, отвечает на тот же вопрос.

## Как гейт опознаёт тип (точность важнее полноты)

- **`design-port`**: источник дизайна открыт, и ПОСЛЕ этого сделано не меньше двух правок
  интерфейсных файлов. Порог нужен: одна правка после открытия макета это точечная правка,
  а не перенос. Порядок тоже важен: макет, открытый ПОСЛЕ правок, это проверка, а не перенос.
- **`code-import`**: `git clone`, `gh repo clone`, `degit`, `svn checkout`, `scp -r`,
  `rsync -a`, скачивание архива.

Команда разбирается **по синтаксису, а не по вхождению подстроки**: кавычки и комментарии
вырезаются до сопоставления. Иначе `echo "сначала git clone, потом сборка"` считалось бы
переносом. Это класс `guard-fires-on-mention-not-action`, который 2026-08-08 уже заставил
сторож разрешений заблокировать собственный коммит.

## Контракт безопасности (не изменился)

- отказ мягкий: любая ошибка, нет транскрипта, не разобрался — пропускаем;
- блокировка не больше одного раза за сессию;
- прежнее поведение по документам не изменено ни на йоту, у него свои одиннадцать проверок;
- если это НЕ перенос (правил своё, макет открывал для справки), достаточно сказать это
  прямо в ответе владельцу.

`node hooks/synthesis-coverage-gate.mjs --self-test` — 48 проверок.
`node scripts/synthesis-coverage-audit.mjs --self-test` — 28 проверок.

## Композируется с

- `~/.claude/CLAUDE.md`, правило «Документ-синтез не сдаётся без сверки» — это его
  расширение с одного типа артефакта на четыре;
- правило «Ресёрч не сдаётся без СОБСТВЕННОГО аудита покрытия» — там дисциплина, здесь
  механика;
- `docs/GATES_MUST_SCALE_WITH_THE_CHANGE.md` — оба про то, что гейт обязан быть исполнимым.
