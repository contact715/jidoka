# Граф знаний спрашивается ПЕРВЫМ, на любом запросе

Установлено владельцем 2026-08-28: «всегда при любом запросе или работе всегда должен
использовать граф связи знания».

До этого правило было слабее и звучало так: «когда пользователь наберёт `/graphify`».
То есть механизм включался по команде, а не по работе, и поэтому почти никогда.

## Что меняется

Граф знаний перестаёт быть инструментом по вызову и становится **первым источником**,
к которому я обращаюсь, прежде чем читать файлы и искать по тексту.

Порядок на любом вопросе о коде, архитектуре, связях или содержании проекта:

1. **спросить граф** — что это, с чем связано, кто зовёт, что сломается при правке;
2. **потом** открывать файлы, и уже прицельно, по адресам из графа;
3. поиск по тексту (`grep`) остаётся, но как проверка гипотезы графа, а не как замена.

Причина простая. Поиск по тексту находит СЛОВО, граф находит СВЯЗЬ. Половина классов в
нашем реестре ошибок это ровно про разницу между ними: «такого нет» после взгляда в один
репозиторий, «никто не зовёт» без обхода вызовов, правка, сломавшая соседа, которого никто
не искал.

## Три состояния, и все три называются вслух

Правило выполнимо только если у него есть ответ на случай отсутствия графа. Замер
2026-08-28 по четырём рабочим деревьям: граф был **в одном из четырёх**.

| состояние | что делаю |
|---|---|
| граф есть и свежий | спрашиваю его первым, ответ несёт адреса из графа |
| графа нет | говорю это ПРЯМО и строю: `graphify add <путь>`. Не притворяюсь, что спросил |
| граф старше кода | называю дату графа рядом с ответом |

Третье состояние опаснее первых двух. Устаревший граф это ВТОРОЙ источник одной правды, а
любая копия правды разъезжается — вопрос только срока. Ответ из графа, который старше
правки, выглядит как знание и им не является.

## Чего это правило НЕ делает

Оно не отменяет чтение кода. Граф отвечает «где и с чем связано», но не отвечает «что
именно здесь написано». Ответ, опирающийся только на граф, без открытия файла, это тот же
класс `research-claim-without-evidence`: похоже на проверку, а проверкой не является.

Оно не применяется к разговорной реплике. На «да, понял» граф не спрашивают.

надо знать, читая правило.

## Родство

- «Такого нет — только после проверки ВСЕХ копий кода» — граф и есть способ увидеть все;
- «Утверждение об отсутствии требует исчерпывающей проверки» (`negative-claim-gate`) —
  граф даёт то самое пространство, которое надо перебрать;
- «Один источник правды» — устаревший граф нарушает его, поэтому дата обязательна.
